Connect / Reconnect QuickBooks Online

About this app: PHA Email Agent is a private internal-use accounting automation tool operated by Prestige Home Automation Ltd. for its own businesses. It is not a publicly distributed app and is not available on the Intuit App Marketplace. The OAuth grant flow described below is initiated by the operator on the operator's own machine and authorizes the operator's own QuickBooks Online company.

How the connect flow works

  1. The operator runs the consent script python -m bootstrap_cli.consent_qbo_prod on the operator's local machine.
  2. The script opens the operator's default browser to the Intuit OAuth consent page (appcenter.intuit.com).
  3. The operator signs in to their Intuit account and selects the QuickBooks Online company to authorize.
  4. Intuit redirects to http://localhost:8400/callback where the script captures the authorization code.
  5. The script exchanges the code for refresh + access tokens and writes the refresh token, realm ID, client ID, and client secret to Microsoft Azure Key Vault under the operator's Azure subscription.
  6. Subsequent automated runs of PHA Email Agent use the refresh token to obtain access tokens as needed; the access token is never stored.

Reconnect flow

If the refresh token is revoked (manually or after 100 days of inactivity per Intuit's rotation policy), the operator simply re-runs python -m bootstrap_cli.consent_qbo_prod. The new refresh token overwrites the previous one in Key Vault atomically.

Why not a hosted Connect page?

PHA Email Agent has no public Connect button because it is not distributed publicly. The OAuth consent flow is initiated only by the operator on their own machine for their own QuickBooks Online companies (currently: Prestige Home Automation Ltd. and Denyer Property Group). No third parties are involved.
