Privacy Policy

Last updated: 2026-05-12 · Effective date: 2026-05-12

1. Who We Are

"PHA Email Agent" (the "Software") is operated by Prestige Home Automation Ltd. ("we", "us", "the Operator"), a company registered in England and Wales. The Software performs internal accounting automation for the Operator and its associated businesses (Prestige Home Automation Ltd. and Denyer Property Group). The Software is not a public service, is not offered to third parties, and does not collect data from any external user.

2. What Data the Software Processes

The Software accesses, on behalf of authorized account owners only, the following types of data:

  • Email metadata and attachments from authorized Microsoft 365 mailboxes (sender address, subject line, attachment file names, attachment binary content for PDF invoices and receipts only).
  • PDF files uploaded to authorized Microsoft OneDrive accounts under a deterministic folder structure (e.g. Accounts/2026/Supplier/...).
  • Invoice metadata extracted from PDFs (supplier name, invoice number, invoice date, total amount, line items where structured by the issuer).
  • Posted-record references from authorized Intuit QuickBooks Online company files (existing Bill / Expense / Purchase / Deposit IDs the Software attaches PDFs to). The Software does not create new QBO records.

3. Where the Data Lives

All processing happens within the Operator's own Microsoft Azure subscription, in the UK South region (uksouth). The Software's only outbound calls are to:

  • Microsoft Graph (graph.microsoft.com) — for email read and OneDrive upload, on behalf of the authorized account owner.
  • Intuit QuickBooks Online API (intuit.com) — for read of posted records and PDF attachment upload, on behalf of the authorized QBO administrator.
  • Microsoft Azure platform services (Key Vault, Storage, Application Insights, Monitor) — under the Operator's Azure subscription.

No data is shared with any other third party. No data is sold, traded, advertised on, or transferred outside of these named services.

4. How Authentication Works

The Software uses standard OAuth 2.0 with refresh tokens. Tokens are explicitly granted by the account owner during a one-time browser-based consent flow and are stored in Microsoft Azure Key Vault under the Operator's Azure subscription, accessible only to the Software's Managed Identity. Tokens are never logged, copied to local files, or shared.

5. Data Retention

PDF copies in the authorized OneDrive accounts are retained per the account owner's normal file retention. Telemetry in Microsoft Application Insights is retained for 30 days. Refresh tokens are retained for the lifetime of the OAuth grant (until the account owner revokes consent).

6. Your Rights

Authorized account owners can:

  • Revoke the Software's OAuth grant at any time via the Microsoft account dashboard (account.microsoft.com) or the Intuit account dashboard (intuit.com). Revocation is immediate and irrevocable until the account owner re-consents.
  • Request a full list of data the Software has processed by contacting accounts@pha.ltd.
  • Request deletion of all PDF copies and metadata from the Operator's OneDrive and Azure resources by contacting accounts@pha.ltd.

7. Security

The Software follows industry-standard practices: OAuth refresh tokens are stored in Azure Key Vault with role-based access control limited to the Software's Managed Identity; secrets are redacted from telemetry before reaching Application Insights; all transport is over TLS; the Software's source code is version-controlled in a private repository accessible only to authorized personnel.

8. Changes to This Policy

This policy may be updated. The "Last updated" date at the top reflects the most recent revision. Material changes (e.g. additional data categories processed, additional third-party services contacted) will be announced to the authorized account owners by email before taking effect.

9. Contact

Privacy enquiries: accounts@pha.ltd
